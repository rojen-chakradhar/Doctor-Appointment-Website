# Doctor Apointment Website

<img src="./assets/images/cover.png" alt="cover image">

## functions
- booking
- multipage
- login / signup page
- catalog
- contacts
- about
- footer
- navbar
- animations
- responsive (pretty much)
- have individual doctors page
- can select date and time
